## 3. 跨组检查点（与程序输出比对的预期差异）

1. A→B：陪伴需求高的狗、荷兰猪、鹦鹉排名大幅上升；仓鼠、守宫、金鱼、乌龟（陪伴需求 1）排名下降。两组分母同为 55。
2. A→C：分母由 55 变 70，过敏友好度 5 的乌龟/金鱼/守宫登顶，友好度 2 的狗/猫/荷兰猪/雪貂排名垫底（狗从 B 组第 2 跌到 C 组第 12）。
3. 并列覆盖：B 组 49/55（狗、鹦鹉）、48/55（兔子、龙猫）、46/55（仓鼠、刺猬、雪貂）、44/55（乌龟、金鱼、守宫）；C 组前三全并列。原表顺序断平。
4. 四舍五入覆盖：如 C 组猫 51.5/70 = 73.6% 显示 74；A 组仓鼠 92.7% 显示 93。

## 4. 浏览器回退与连点步骤（#/quiz，配合 A 的 QuizPage）

1. 从首页进问卷：一题一屏，进度条显示第几题/共 8 题（不得写死 6）。
2. 逐题单选自动推进；第 3 题「返回上一题」回第 2 题，原选择保留；改选后推进，最终结果基于新选择。
3. 第 1 题改选住房（dorm ↔ two-bed）走到末题，两轮结果应有差异（对应 A、B 两组预期）。
4. 同一选项快速连点：只推进一题、不跳题（QuizPage 有 400ms 冷却）。
5. 末题后出现「8 题答完了」与重新测；重新测清空 petitch.answers.v1 回到第 1 题。
6. 中途刷新：应回到第一个未答题（答案已存 sessionStorage）。
7. 旧答案残留：浏览器里含已删除选项 id 的旧答案整体作废（quizSession 校验）。
